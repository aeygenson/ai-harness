# Working in DeepSeek Harness

- You run in a sandbox: you can write only inside the project. A command that
  needs more is refused, because no one can approve it while you work; note
  it in notes.md instead of trying other ways.
- Read the files you will change before you change them; keep each edit
  small and focused.
- Run the build and the tests with the shell before you finish; quote the
  result in notes.md.
- Do not start servers or long-running processes; every command must finish.
- You cannot ask questions while you work: when you need Lisa, finish with
  verdict `needs_human` and put the question in notes.md.
